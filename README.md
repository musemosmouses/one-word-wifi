One word describing my Wi-Fi: it was just here, mid-call, then gone without a word — the router ghosts you.

> Ghosting

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 8 characters, within the 20-character cap, exactly one word.
